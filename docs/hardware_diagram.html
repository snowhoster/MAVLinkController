🛠️ 萬用洞洞板四大焊接實務工法與檢驗規範

  1. Row H 裸銅線貫穿接地工法： 選用 0.8mm 鍍錫裸銅線 拉直橫跨整排 Row H（Col 4 至 Col 35）。兩端折入孔中固定焊牢，將所有元件接地腳直接向 Row H 靠攏折腳拖焊。阻抗趨近於 0Ω，徹底杜絕各訊號地迴路雜訊。
  2. Row F 分壓節點拖焊錫橋工法： 左油門 (16-F, 17-F, 18-F) 與右油門 (20-F, 21-F, 22-F) 在背面引腳留 2mm，分別折向中央相鄰焊盤。塗抹微量松香助焊劑，以烙鐵刀頭沾取焊錫拖焊成一顆飽滿光亮的淚滴型錫球。結構堅固、導電優良且無需額外飛線！
  3. 外置 18650 UPS 與 Type-C 供電架構： 雙節 18650 電池座獨立固定於遙控器外殼底槽，利用 15cm 軟質矽膠 Type-C 線直插 Arduino UNO Q 主板 Type-C 埠；全板 5V 電源由 UNO Q Power 8P 的 Pin 5 (5V) 引出至洞洞板 Row C 供電軌，專門轉供雙 APEM 霍爾推桿。
  4. 通電前三級萬用表防短路測試（必做）：
    • 電源短路檔：蜂鳴檔測 5V 對 GND、3.3V 對 GND，必須為開路（無蜂鳴）。
    • 分壓下阻抗檔：歐姆檔測 (17, F) 與 (21, F) 對 Row H GND，數值必須精確為 20kΩ ±1%。
    • 分壓上阻抗檔：歐姆檔測插座 Pin 2 對 (17, F) 與 (21, F)，數值必須精確為 10kΩ ±1%。
